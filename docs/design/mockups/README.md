# UI mockups

The screen mockups that `docs/DESIGN_SYSTEM.md` (Screen map) refers to. Each file is
`NN-screen-name.png`. Open the matching image before changing a screen.

| File | Screen | State |
|---|---|---|
| `01-grocery-list-filled.png` | Grocery List | filled (items, checkboxes) |
| `02-meal-planner-week-filled.png` | Meal Planner, week view | filled (one meal per slot) |
| `03-account-signed-in.png` | My Account | signed in (menu) |
| `04-recipe-detail.png` | Recipe detail (Ramen) | filled (no route yet, N-01) |
| `05-welcome-signed-out.png` | Welcome / sign up | signed out |

All five are light mode. There are no dark-mode mockups.

The brand boards (palette and logo usage) are in `../brand/`.
